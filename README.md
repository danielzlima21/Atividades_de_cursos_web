# Atividades e Projetos de Cursos

Este repositório foi criado com o objetivo de centralizar, organizar e registrar o meu progresso prático em cursos, formações e workshops de tecnologia. Aqui se encontram os códigos-fonte, laboratórios e projetos desenvolvidos ao longo da minha jornada de aprendizado.

A estrutura do repositório é dividida em pastas correspondentes a cada instituição ou curso focado no desenvolvimento de software.

---

## Cursos Concluídos / Em Andamento

### 1. Fundação Bradesco - Desenvolvimento Web (Site Simples)
* **Status:** Concluído
* **Tecnologias:** HTML5, CSS3, JavaScript (Vanilla)
* **Descrição:** Projeto prático de uma lista de tarefas (Task List). O foco foi a estruturação semântica, o uso de variáveis nativas do CSS para a criação de um sistema de temas dinâmico e a manipulação do DOM via JavaScript para alternar entre os modos Claro (Light) e Escuro (Dark).
* **Pasta do projeto:** `/fundacao-bradesco-site-simples`
